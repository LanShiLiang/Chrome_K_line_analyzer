# K 线量价分析器常见问题

[English](./FAQ.md) | [简体中文](./FAQ.zh-CN.md)

## 为什么默认使用英文？

英文可以为未支持的 Chrome 语言提供一致回退，并覆盖 Binance 用户和全球 Chrome Web Store 受众。插件仍完整支持简体中文，为同花顺和 A 股用户服务。

## 插件如何选择语言？

插件使用 Chrome 扩展国际化机制和 Chrome 界面语言，不提供独立语言设置。未支持的语言回退英文。

## 代码内部的 `BUY`、`MARKUP` 等关键字会被翻译吗？

不会。内部动作值、阶段、错误码和原因码始终保持稳定的英文机器标识，只有渲染给用户的显示标签经过国际化。

## 插件会上传行情或分析结果吗？

不会。分析在本地执行，结果不上传至开发者服务器。公开行情请求直接发送至 Manifest 声明的 Binance 或同花顺接口。

## 为什么 TradingView 的策略设置被锁定？

TradingView 只使用当前页面已经推送的数据。插件跟随当前图表周期和实际捕获的 K 线数量，不另行主动请求或覆盖页面上下文。

## 为什么 K 线不足时不直接用较少数据计算？

用户选择的 K 线数量是完整的分析和图表窗口。如果静默缩短窗口，图表与策略计算就会不一致，因此插件会明确显示数据不足错误。

## 这是自动交易工具吗？

不是。插件不会下单，不访问交易账户，不保证预测结果，也不承诺收益。输出仅用于可解释的技术研究。
