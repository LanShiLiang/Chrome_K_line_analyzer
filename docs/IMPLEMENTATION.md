# 实现说明

## 决策记录

| 决策 | 实现 | 原因 |
|---|---|---|
| UI 宿主 | 独立弹出分析窗口 | 不改变目标网站 DOM 布局，MVP 调试稳定 |
| 数据捕获 | Inject Script Hook Fetch/XHR | Content Script 隔离世界无法直接覆盖页面请求函数 |
| 适配方式 | 通用 OHLCV 解析器 + 后续注册表扩展 | 文档未指定目标站点，不臆造站点私有协议 |
| 策略计算 | 纯函数 | 可测试、可复现、可迁移到 Web Worker |
| 数据存储 | Chrome Storage 配置；运行数据按 Tab 内存保存 | 避免保存原始响应和敏感数据 |

## 当前边界

- MVP 支持 Fetch 和 XHR，不支持 WebSocket 行情流。
- 通用解析器优先识别数组和对象 OHLCV；复杂嵌套响应需增加站点适配器。
- 框选范围用于交互确认；未获得图表坐标轴映射时，不以像素坐标裁切时间范围。
- 正式发布前应将 Manifest 的宽域名权限替换为已验收站点白名单。
