# v0.1.4 框选暂停与体验回归记录

## 变更

- 通过 `src/shared/features.ts` 统一暂停框选入口、页面遮罩、旧选区消息和自动分析。保留算法源码及单测，重新开放前须补回选区端到端验收。
- 最终生产 JS 不包含 `captureVisibleTab`、框选按钮或遮罩标记；正常的 Binance / 同花顺主动行情、被动回退及 TradingView 被动路径保留。
- 主操作区改为单列，展示下次分析的周期和根数；沿用蓝色主题及原设置图标的悬停效果。
- 区分“应用设置”和“开始分析”；记住配置的文案明确包含周期、数量和下次不再弹窗。
- 弹窗支持 Tab / Shift+Tab 焦点循环、Esc 关闭并恢复焦点、Enter 提交；背景不可聚焦。保存失败保留草稿并提示重试，保存中禁止重复提交。
- 保存期间切换标签页关闭旧弹窗，迟到保存不会触发新标的分析。
- 去掉 Popup 打开侧栏前固定的 180ms 等待。同步中英文使用说明、扩展简介、隐私说明与商店文案草稿；未提交商店审核。

## 测试过程中修正

- 首次站点访问被沙箱网络限制拦截；取得授权后在独立测试浏览器中重跑。
- Enter 用例最初只发送键名，缺少原生回车文本；补全 CDP 键盘事件后，实际表单提交与失败重试通过。
- 原主题单测固定断言双列布局，已更新为本版本单列操作区；保留蓝色及市场涨跌色断言。
- 原生侧栏调整宽度后，默认截图裁剪范围可能滞后；改为明确指定当前视口，低高度弹窗仅截取可见区域，避免把视口外背景混入证据。
