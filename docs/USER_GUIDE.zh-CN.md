# K 线量价分析器用户指南

[English](./USER_GUIDE.md) | [简体中文](./USER_GUIDE.zh-CN.md)

## 安装

1. 下载并解压发布 ZIP，或执行 `npm run build` 构建插件。
2. 在 Chrome 中打开 `chrome://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”。
4. 选择生成的 `dist` 目录。
5. 可按需把 K 线量价分析器固定到工具栏。

## 选择支持的行情页面

- Binance：打开 [BTC/USDT](https://www.binance.com/en/trade/BTC_USDT?type=spot) 等现货交易页。
- 同花顺：打开 [600519](https://stockpage.10jqka.com.cn/600519/) 等个股页面。
- TradingView：打开图表并等待页面推送行情数据；这是被动兼容路径。

安装或重新加载插件后，需要刷新行情页面。

## 开始分析

1. 点击浏览器工具栏中的 K 线量价分析器图标。
2. 选择“打开侧边分析面板”。
3. 确认面板已经识别当前支持的站点。
4. 点击“开始分析”，确认周期和 K 线数量后开始。主按钮下方会显示下次分析的参数。
5. 插件获取最近的指定行情区间；加载期间可以安全取消。
6. 查看策略结论、阶段、置信度、分析依据，以及“本次分析区间”中最终用于计算的标的、周期、根数和起止时间。

v0.1.4 暂时屏蔽框选入口，不创建框选遮罩、不截取选区图片，也不自动运行框选分析。可通过设置按钮更改分析窗口。

设置支持 Tab / Shift+Tab 切换焦点、Esc 关闭、Enter 提交。“应用设置”只更新下次分析的参数，不立即运行。保存失败时保留弹窗和草稿，可直接重试。勾选记住配置会保存周期与根数，之后开始分析不再弹窗。

## 策略设置

Binance 和同花顺支持 30 分钟、1 小时、4 小时、日、周、月周期。数量输入框编辑时可以清空，合法范围为 5–1000；非法草稿只在本地提示，不会发送行情请求。合法的同一个 K 线数量设置同时控制分析和图表，并保存在本地。

TradingView 跟随当前图表周期和实际捕获的数据，策略设置在界面和后台处理层均保持锁定。

## 语言

插件默认使用英文。当 Chrome 界面语言为简体中文时，插件名称、Popup、Side Panel、错误、警告、阶段、信号和分析依据均显示简体中文。其他未支持的 Chrome 语言回退英文。

插件没有独立的语言选择器。需要修改 Chrome 界面语言并重启 Chrome 才能改变插件语言。

## 隐私

行情数据和分析结果仅保留在浏览器运行内存中，不上传至开发者服务器。本版本不截取选区图片。主动公开行情请求直接发送至 Binance 或同花顺，不携带 Cookie 或登录凭证。完整说明见中英双语[隐私政策](../PRIVACY.md)。

## 故障处理

- 面板未找到行情时，刷新受支持页面并等待图表加载。
- 重新加载插件后，需要刷新行情页面以替换旧的 Content Script 和 Inject Script。
- 分析期间页面或标的发生变化时，等待同步完成后重新分析。
- 输入少于 5 根时请输入至少 5 根；非法草稿仍可编辑，不会发送行情请求。
- TradingView 可用性取决于当前图表已经推送的数据，日常使用推荐 Binance 或同花顺主动路径。
